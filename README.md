# Bang Story Character Sheets

Lembar karakter untuk referensi **emix.ai** di aplikasi Bang Story.

File di sini di-upload otomatis oleh aplikasi saat generate (folder `character-sheets/`),
lalu URL `raw.githubusercontent.com`-nya dikirim ke emix.ai sebagai `image_urls`.
emix.ai perlu URL yang bisa diakses publik — karena itu repo ini **public**.
